# Decisions

Append new entries; supersede old ones instead of editing them.

## D001: Native engines, no Python runtime (2026-11-25)
Ship sherpa-onnx and acestep.cpp as child processes managed by Rust. The brief's FastAPI and Docker stack would require large installs and favours NVIDIA cards. It stays an option only for models without native ports.

## D002: Kokoro fp32 is the default voice model (2026-11-25)
int8 was 3.4× slower on the test CPU. Revisit for low-memory machines.

## D003: Pin sherpa-onnx to 1.13.8 (2026-11-25)
2.x silently drops numbers and unknown words. Upgrading requires a phonemizer and a passing transcription test.

## D004: ACE-Step replaces MusicGen (2026-11-25)
MusicGen weights are non-commercial. Default: ACE-Step 1.5 turbo Q4_K_M with the 0.6B LM.

## D005: Vulkan on Windows, Metal on macOS, CPU fallback (2026-11-25)
One Windows backend covers NVIDIA, AMD and Intel, and needs no CUDA install.

## D006: Piper is not a default (2026-11-25)
It is fast, but each voice carries its own licence. Add voices only after individual review.

## D007: GPL-3.0 app licence (2026-11-25)
Compatible with the bundled GPL-3.0 espeak-ng component and keeps forks open. Owner may revisit before outside contributions arrive.

## D008: Models download after install (2026-11-25)
Weights total about 3.6 GB. Installers stay small; generation works offline once models are installed. Downloads are pinned and checksum-verified.

## D009: Next.js static export (2026-11-25)
Tauri has no Node server. All privileged work goes through typed Rust commands.

## D010: Branching (2026-11-25)
`feature/*` from `dev`, merged to `dev`; releases are PRs from `dev` to `main`.

## D011: SvelteKit static replaces Next.js (2026-11-25)
Supersedes D009. Next.js server features cannot run in Tauri. UI JavaScript fell from 767 KB to 332 KB and total UI output from 1.55 MB to 0.45 MB. The UI is client-only (`ssr = false`) with an `index.html` fallback. shadcn-svelte provides the shadcn/ui components.

## D012: Small installer (2026-11-25)
Release builds optimise for size (opt-level s, LTO, one codegen unit, abort on panic, stripped). Measured Windows installer: 1.3 MB for the app, 11.4 MB in a test that also packed both engines (Vulkan and CPU). Engines ship in the installer; models never do. Only Latin font files are bundled; other scripts use system fonts.

## D013: Model hosting (2026-11-25)
Extends D008. Hugging Face is primary, pinned to a commit. Cloudflare R2 is the backup mirror, added when needed. The manifest lists several URLs per file, and every file must match its SHA-256 whichever source served it. Voice (about 370 MB) and music (3.28 GB) are separate packs.

## D014: Model manager (2026-11-25)
`src-tauri/models.json` is generated by `scripts/build-manifest.mjs` from pinned commits; never edit it by hand. Files download to `.part` and are renamed only after SHA-256 passes. Sources are tried in order, three attempts each. Recommended memory is 4 GB for voice and 8 GB for music, as guidance rather than a block.

## D015: Custom models folder (2026-11-25)
Users can keep models on any drive. Models always live in a `VoxMelody Models` folder inside the chosen one, so unrelated files are never touched. Moves hard-link within a drive or copy and verify across drives; the original is deleted only after the new location is saved. A missing custom folder shows Relink and never falls back silently. Paths come only from the system folder picker, never from the page. The app's own install folder is chosen in the Windows installer.

## D016: Open model catalog later (2026-11-25)
Users may download any compatible model, with recommended ones as defaults, and mark favourites (Phase 7). It is deferred because it needs engine support per model family, a variable number of packs in the UI, and licence display. Until then keep pack ids and file lists in the manifest, not in Rust.

## D017: Own voice engine process (2026-11-25)
`engines/voice` is a small Rust program using the official sherpa-onnx 1.13.8 bindings, statically linked. It reads JSON lines on stdin and stays loaded between requests, stopping after two idle minutes. It runs inside the voice pack folder with relative paths because the library cannot open non-ASCII paths on Windows. Cancelling kills the process. It replaces the stock command-line tool. Built by `pnpm engines` and bundled as a Tauri sidecar.

## D018: Engine is suspended for model changes (2026-11-25)
Removing or moving models suspends the voice engine first and holds it stopped, so model files are never in use. Any new engine must follow the same rule.

## D019: Takes are temporary until the Library exists (2026-11-25)
Only the newest preview and newest recording are kept in the cache; Export saves a WAV. Phase 5 makes recordings permanent. Compressed export formats are undecided.

## D020: Own music engine process (2026-11-25)
`engines/music` is a small C++ program built on acestep.cpp `973517b`, fetched by CMake at build time. It reads one JSON line on stdin, makes one track and exits, so all memory returns to the computer. Windows loads Vulkan and the best CPU variant at runtime, so PCs without Vulkan still work and no Visual C++ runtime is needed. Backends load before the engine enters the models folder, so libraries are never loaded from it. Building on Windows needs Visual Studio with CMake and the Vulkan SDK.

## D021: Exact music length (2026-11-25)
The engine composes past the requested length, retries up to three times if the music stops early, and renders only what is needed plus two seconds. The app trims silence, cuts, fades and normalises. A track with a silent ending is composed once more, then repeated with a crossfade as a last resort. Loudness targets −14 LUFS but peaks never exceed −1 dBFS; there is no limiter until Phase 6, so dynamic tracks land lower.

## D022: Music device choice (2026-11-25)
Music uses the dedicated GPU with the most memory if it has at least 3.5 GB, otherwise the CPU. Integrated GPUs are skipped until tested. If the GPU run fails, the same track restarts on the CPU, which is then used until the app restarts. The VAE tile is 256 frames: faster, with peak graphics use under 2 GB.

## D023: Music is instrumental for now (2026-11-25)
Lyrics and vocals are outside Phase 4. Length is 10 to 240 seconds; tempo and key default to Auto.

## D024: Shared takes (2026-11-25)
Extends D019. Voice and music share one temporary take store and one read and export path. Removing a model suspends only its own engine; moving models suspends both.

## D025: Library storage (2026-11-25)
Supersedes D019 and D024 for finished recordings. Every generated voice and music track is kept automatically as a WAV in the `VoxMelody` folder of the system Music folder, or in the app data folder if that is unusable. Previews stay temporary. The index is `library.json` in the app data folder: written atomically, with one backup, under a file lock so two windows agree. No database is needed.

## D026: Identifying recordings (2026-11-25)
A recording is recognised by its size plus a hash of its start and middle. Size alone fails because tracks of equal length have equal size. Relink only accepts the same recording and also finds others moved beside it. Delete never removes a file that is not the recording. Rename changes the title only; file names stay.

## D027: Mix (2026-11-25)
Mix is its own page: one voice and one music recording from the Library, with music volume, intro and outro. The voice sets the length; longer music is cut and shorter music repeats with a crossfade, without its faded ending. Mixes are saved to the Library as a third kind with the voice's title. Mixing runs inside the app in plain Rust: no engine process, model or new dependency.

## D028: Ducking and loudness (2026-11-25)
Music sits 12 to 28 dB below speech (20 by default) and rises 10 dB in pauses longer than about a second. The level depends on measured loudness, so quiet recordings need no adjustment. Supersedes the missing limiter in D021: a lookahead limiter takes mixes and music tracks to −14 LUFS with peaks at −1 dBFS, with at most 12 dB of reduction; extremely peaky audio lands lower.

## D029: Simple by default, Advanced on request (2026-11-25)
Models has its own page. Simple shows the recommended voice and music model, plus any already downloaded. One Advanced switch, shared by Models and both studios, shows the full catalog with details and filters, and every engine control. Hidden controls never affect a result.

## D030: Model catalog (2026-11-25)
Supersedes D016. The catalog is curated: each model runs on an engine we ship and was tested. Details live in `models.json`; the first model of a kind is recommended, and the original pack ids stay so existing downloads keep working. Four voice models beyond Kokoro and three music models beyond Turbo are listed. Kokoro int8 is left out (D002).

## D031: Shared model files (2026-11-25)
Music models share files. Identical files are hard-linked from installed models, so they are downloaded and stored once; drives without links download them again. Removing a model never affects another.

## D032: Use restrictions (2026-11-25)
Models with restricted licences, currently Supertonic 3 (OpenRAIL-M), may be listed with a visible notice and a link, by the owner's decision. Non-commercial models stay out. People download the weights from Hugging Face; the app never redistributes them.

## D033: Preferences (2026-11-25)
`preferences.json` in the app data folder keeps Advanced, chosen models and favourites. A damaged file resets them.

## D034: Voice cloning with Pocket TTS (2026-11-25)
Phase 9 ran before Phase 8 by the owner's decision. Cloning uses Pocket TTS (100M, CC-BY-4.0, English, 198 MB) through the existing voice engine; it needs no transcript. ZipVoice was rejected because its training data (Emilia) is non-commercial. Kyutai's own page asks people to accept its prohibited uses before downloading; the pinned sherpa-onnx conversion does not, so the app shows the restriction notice and its own consent step. The owner should confirm this source before release.

## D035: Consent for cloned voices (2026-11-25)
A voice is created from a recording of a spoken consent statement or from a file. Both need a stated owner and a confirmation that Rust also requires, and the choice and time are kept. Nothing checks that the speaker is who they say. Every recording and mix with a cloned voice is marked Cloned in the Library and carries a comment inside the file saying it is AI-generated.

## D036: Cloned voice samples (2026-11-25)
Samples stay in `voices` in the app data folder, never in the models folder. The page decodes any audio format and sends mono 24 kHz samples; Rust trims, levels, cuts at a pause (5 to 15 seconds) and adds half a second of silence before and 0.3 after. Without that silence, openings were often lost or gained words.

## D037: Claude Code connection (2026-11-25)
`voxmelody mcp` runs the same app without a window as a Model Context Protocol server on stdin and stdout: no port, no network, no new dependency. It uses the same commands and checks as the app, and ignores undocumented arguments. Tools: list voices, generate speech, generate music, create mix, list recordings. Cloned voices are excluded, so speech in a person's voice is only made in the app.

## D038: Songs with lyrics (2026-11-25)
Supersedes D023 on lyrics. Music Studio has Instrumental and Song. Both use the same ACE-Step models; songs send lyrics and an optional language. People always write the lyrics: the 0.6B model writes nonsense and the 1.7B ignores the description. Songs are a fourth Library kind and are not offered in Mix, where ducking expects music without singing.

## D039: Song length (2026-11-25)
Songs keep their own ending: they are never looped or cut to an exact length. Auto estimates the length from the lyrics (20 to 240 seconds). A song that stops mid-music is composed once more with a quarter more time, then accepted with a short fade.

## D040: Song languages (2026-11-25)
Listed by name when at least 80% of the sung words were recognised with the recommended model: English, French, German, Italian, Korean, Polish, Portuguese, Spanish and Turkish. Any other language works through Auto, without a promise of quality.

## D041: Small graphics work units (2026-11-25)
The engine sets `GGML_VK_MAX_NODES_PER_SUBMIT` to 4. At the default of 100, Windows reset the graphics driver during audio decoding on the GTX 1060 (its limit is two seconds per task). Speed is unchanged.

## D042: DiffRhythm is not offered (2026-11-25)
DiffRhythm 1's decoder has the Stability AI Community Licence, and DiffRhythm 2 has no maintained native runtime. Revisit when one exists.
